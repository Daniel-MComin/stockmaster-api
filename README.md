Stock Master

Stock Master é um sistema de gerenciamento de estoque desenvolvido com Angular no front-end e Django Rest Framework no back-end. O sistema permite a gestão eficiente de produtos, categorias e movimentações de estoque, garantindo segurança com autenticação JWT.

Tecnologias Utilizadas

Front-end:

Angular (Framework principal)

Angular Material (Componentes de UI)

Angular Router (Roteamento de páginas)

Formulários Reativos (Gerenciamento de inputs do usuário)

Back-end:

Python

Django Rest Framework (DRF) (Criação de APIs RESTful)

JWT Token (Autenticação e segurança)

SQLite (Banco de dados)

Funcionalidades

Cadastro, edição e exclusão de produtos

Gerenciamento de categorias

Autenticação segura com JWT

Painel administrativo com estatísticas
